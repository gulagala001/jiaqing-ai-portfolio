# Jiaqing Wang · AI product explorations

Personal projects in development, built through requirements, AI-assisted implementation and repeated trials.

- **TriSoul**: a DeepSeek Harness extension exploring complementary generation, anonymous peer selection, divergence feedback and long-task context.
- **PenEcho**: application integration around persistent handwritten projects, an independently running Android client and project-file synchronization. Built on PenEcho, pi Agent and Syncthing; device acceptance is still pending.
- **VoxelBench**: a self-proposed evaluation concept for complete delivery and state-preserving follow-up changes. Five partially scored records; no completed second-round evaluation.
- **Vibex**: a FanBox adaptation exploring visibility and human control during agent work.

The homepage and four case pages distinguish mechanism illustrations, actual UI screenshots and model-generated evaluated artifacts. PenEcho UI evidence uses a simulated model and synchronization service.

Static site, no model keys or backend. Private CVs and application records are excluded. Scoring interactions are temporary and do not modify original records.
